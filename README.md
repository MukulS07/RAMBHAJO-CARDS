# Rambhajo director card

Tap-to-open NFC business card for Rambhajo by Advit Jewels.

**Open it:** double-click `index.html`.

**Change the details:** open `index.html`, scroll to `const CARD = {` near the bottom and edit the values.

**Add a photo:** put it in `assets/photos/` and set `photo: "assets/photos/yourfile.jpg"`.

**Put it online:** drag this folder onto [Netlify Drop](https://app.netlify.com/drop), or upload it to your website. Write the resulting `https://` link to the NFC card with the NFC Tools app.

**Working with Claude Code:** open this folder in Claude Code. It reads `CLAUDE.md` for the full project brief, the design decisions to keep, and how to test.
